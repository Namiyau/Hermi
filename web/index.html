Quick start

使用指南

从会话开始

左侧可新建或切换会话；右侧“设置”里的“能力”可为下一条请求选择合适流程。

查看 Token 使用量

点击左下角括号中的账户名称，可查看剩余额度；“账户设置”里可查看和修改自己的基础信息。当前会话用量在右侧“设置”的会话统计中。

修改会话名称

把鼠标移到左侧会话名称上，点击铅笔图标，直接输入新名称后按对勾保存。

审批与外部操作

文件、联网、QQ、定时和本机操作会按权限与审批执行；不要把 token 或私人信息发到会话里。

聊天模式与能力

聊天模式更接近日常对话；专业模式会把角色名称、思考过程和正文按工作流展开。能力一次只选择一项，可在输入框上方点 × 取消；发送完成后会自动清除本次选择。
